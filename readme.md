# Comparative Analysis of AI-Generated and Human YouTube Channels

## Overview

This project was completed as part of my Master's research work. The objective was to compare AI-generated and human-created YouTube channels using publicly available metadata to identify differences in channel growth, video performance, and audience engagement.

## Objectives

- Compare AI-generated and human-created YouTube channels.
- Analyze engagement metrics and channel performance.
- Perform exploratory data analysis and statistical comparisons.
- Visualize trends and patterns using Python.

## Dataset

The analysis uses metadata collected through the YouTube Data API, including channel and video information such as subscribers, views, likes, comments, upload dates, and video duration.

> **Note:** The raw dataset is not included in this repository because it was collected using the YouTube Data API and is not redistributed here.
